# Kai Shang Garden Landscaping – website

The whole site lives in one file: `index.html`. Open it in a browser to view it.

- Pages (Home, Build, Maintain, Projects, About, Contact) all live inside `index.html`.
- It was exported from the design mockup in `Retaining walls site mockup.zip`.
- Photos are loaded from the current ksgnl.com site, so they need an internet connection.

## Publishing with GitHub Pages
Repo **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** → Save.

## Undo
To remove this build, revert the commit that added `index.html` (on GitHub: open the commit → "Revert").
